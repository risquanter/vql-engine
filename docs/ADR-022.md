# ADR-022: Typed Refusals

**Status:** Accepted
**Date:** 2026-11-12
**Tags:** error-handling, parsing, boundary, consumer-contract, lexer

---

## Context

- A refusal is a `Left` the engine returns because of what the caller typed. A
  consumer that shows or logs a refusal must know what text it holds.
- A composed sentence has no content type. A sentence built from token text or
  an exception message can carry any part of the caller's query.
- A consumer that branches on a sentence parses text the engine wrote, and
  breaks when the wording moves.
- A boundary that converts every exception into a refusal reports a defect as
  the caller's mistake.
- An offset that is estimated reads exactly like an offset that is measured.

---

## Decision

### 1. One case per sentence template, holding the values the sentence is built from

Each refusal is a case of a closed `enum`. The sentence is a derived `message`,
never the only carrier.

```scala
enum ParseRefusal:
  case IntegerExpected(part: QuantifierPart, found: Found)
  case SymbolExpected(expected: GrammarSymbol, before: ParseContext, found: Found)
  case FractionOutOfRange(numerator: Int, denominator: Int)
  case Formula(failure: SyntaxFailure)
  case Lexical(failure: LexFailure)
  // … one case per template

  def message: String = this match
    case FractionOutOfRange(k, n) => s"Fraction $k/$n must lie in [0, 1] with a positive denominator"
    // …
```

The sets are `LexFailure`, `SyntaxFailure`, `parser.ParseError`,
`ParseRefusal`, `QueryError.ValidationProblem`, `QueryError.EvaluationFailure`
and `TypeCheckError`.

### 2. A token is carried by its kind, and text only where its content is bounded

```scala
enum TokenKind:
  case Word(text: WordText)          // [A-Za-z0-9_']+
  case Decimal(text: DecimalText)    // digits.digits
  case Literal(content: LiteralText) // the literal alphabet
  case Symbol(symbol: GrammarSymbol) // punctuation and the known operators
  case UnknownOperator               // no text
  case StrayCharacter                // no text
```

`WordText`, `DecimalText` and `LiteralText` are opaque types built through a
`require` (ADR-012). A name in a refusal is a `VariableText` or a `SymbolText`
built from them. A `SymbolText` may be an operator, because an infix relation
names an atom and an infix operator names a function application.

### 3. A quoted literal admits a fixed alphabet

`Lexer.literalChars` is `[A-Za-z0-9 /_.+-]`. Any other character inside quotes
is `LexFailure.RefusedLiteralCharacter`, with its offset. The apostrophe is
outside the alphabet.

### 4. A position is a type, and "no position" is one of its cases

```scala
enum SourcePosition:
  case At(offset: Int) // a UTF-16 code-unit offset into the input
  case Unknown
```

A site reports `At` only where the offset is exact. A lexer refusal is `At`.
Every other site reports `Unknown`.

### 5. A boundary converts only the parsers' own failures

`FOLParser.parseWithLexer` and `VagueQueryParser.parse` catch `LexerError`,
`Combinators.ParseFailure` and `Combinators.SyntaxError`. `VagueQueryParser`
also catches `QueryException`. Any other exception propagates.

```scala
catch
  case e: QueryException => Left(e.error)
  case e: LexerError     => Left(QueryError.ParseError(ParseRefusal.Lexical(e.failure), SourcePosition.At(s.length - e.remaining)))
  case e: ParseFailure   => Left(refused(ParseRefusal.Formula(e.failure)))
  case e: SyntaxError    => Left(refused(ParseRefusal.Formula(e.failure)))
```

## Code Smells

### ❌ A sentence as the only carrier

```scala
// BAD: the consumer must parse the operator back out of the text.
QueryError.ParseError(s"Invalid quantifier operator: $op", input)

// GOOD: the case holds the token's kind; the sentence derives from it.
QueryError.ParseError(ParseRefusal.UnknownQuantifierOperator(TokenKind.of(opTok)), SourcePosition.Unknown)
```

### ❌ Unbounded token text in a refusal

```scala
// BAD: an OpSym holds any run of symbolic characters the caller typed.
case UnknownOperator(text: String)

// GOOD: the kind carries no text.
case UnknownOperator
```

### ❌ A catch-all at a boundary

```scala
// BAD: a defect in the parser becomes the caller's parse error.
catch case e: Exception => Left(QueryError.ParseError(e.getMessage, s))

// GOOD: name the parsers' own failure types; anything else propagates.
catch case e: SyntaxError => Left(refused(ParseRefusal.Formula(e.failure)))
```

### ❌ An estimated offset reported as a position

```scala
// BAD: exact only when the leftover text is spaced as tokensLabel renders it.
Some(s.length - tokensLabel(remaining).length)

// GOOD: an offset that is not measured is Unknown.
SourcePosition.Unknown
```

## Cross-ADR Relationship

- **ADR-007.** The foundation keeps `throw`, tuple threading and every
  `try/catch`. Its throws carry a typed `SyntaxFailure`, whose `message` is the
  OCaml text. ADR-007's review criterion records this.
- **ADR-002 and ADR-012.** The two `Either` boundaries stay where they are.
  This record narrows what each converts.
- **ADR-017.** `ParsedQuery.mk` throws its two range rules as
  `ValidationProblem` cases behind `VagueQueryParser.parse`.
- **ADR-006.** Every set is a pure-data `enum` with a derived `message`.
  `QueryError` stays a `sealed trait`.
- **ADR-023.** A sort or a symbol name in a refusal is a `TypeId` or a
  `SymbolName`, declared in `vql.id`.

## Alternatives Rejected

### Text fields as `String`, with their content stated in scaladoc and pinned by a test
- **What:** keep a word, a literal's content and a name as `String`.
- **Why rejected:** the content is then a statement and a test, and no type
  holds it. A value outside it can exist and reach a consumer.

### One formula case with no fields
- **What:** the boundaries catch the foundation's plain `Exception` and return
  `Formula(Malformed)`.
- **Why rejected:** a boundary that catches `Exception` cannot tell a refusal
  from a defect, and nine throw sites collapse into one case with no detail.

### The trailing-tokens offset as an estimate
- **What:** report `s.length - tokensLabel(remaining).length` as `At`.
- **Why rejected:** the value is wrong whenever the leftover text is spaced
  differently from how `tokensLabel` renders it, and nothing marks which.
